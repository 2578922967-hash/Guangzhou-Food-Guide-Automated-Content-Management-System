# 广州美食内容管理系统 - 前端

## 功能特性

### ✅ 已实现功能

1. **餐厅列表展示**
   - 表格展示餐厅信息
   - 支持显示名称、菜系、商圈、价格、评分等字段
   - 响应式设计，适配移动端

2. **筛选功能**
   - 按名称搜索（模糊匹配）
   - 按菜系筛选
   - 按商圈筛选
   - 按星级筛选
   - 按价格区间筛选（最低/最高价格）
   - 按味道评分筛选

3. **排序功能**
   - 支持按名称排序
   - 支持按价格排序
   - 支持按味道评分排序
   - 支持按评论数排序
   - 升序/降序切换

4. **分页功能**
   - 客户端分页
   - 可调整每页显示数量（10/20/50/100）
   - 页码导航
   - 显示总记录数

5. **用户体验优化**
   - 加载状态提示
   - 错误提示
   - 空状态提示
   - 表格悬停效果
   - 响应式布局

## 技术栈

- **React 18** - UI 框架
- **TypeScript** - 类型安全
- **Vite** - 构建工具
- **Axios** - HTTP 客户端
- **CSS3** - 样式（原生 CSS，无 UI 框架）

## API 集成

前端通过 Vite 代理连接到后端 API：

- 开发环境：`http://localhost:5173` → 代理到 `http://localhost:8000`
- API 端点：`/api/restaurants/`, `/api/templates/`, `/api/reports/`

## 功能说明

### 筛选功能

1. **名称搜索**：输入餐厅名称，支持模糊匹配
2. **菜系筛选**：下拉选择菜系类型
3. **商圈筛选**：下拉选择商圈
4. **星级筛选**：下拉选择星级
5. **价格筛选**：输入最低/最高价格
6. **评分筛选**：输入最低味道评分

### 排序功能

点击表头可排序的列（名称、价格、味道评分、评论数）：
- 第一次点击：降序
- 第二次点击：升序
- 第三次点击：取消排序

### 分页功能

- 使用分页器切换页面
- 调整每页显示数量
- 查看总记录数

## 故障排查

### 前端无法连接后端

1. 检查后端是否启动：`curl http://localhost:8000/api/health`
2. 检查浏览器控制台错误
3. 检查 Vite 代理配置

### 数据不显示

1. 检查 API 响应数据格式
2. 检查浏览器 Network 标签
3. 查看控制台错误信息

### 筛选不生效

1. 检查筛选参数是否正确传递
2. 检查后端 API 是否支持筛选
3. 查看网络请求参数
